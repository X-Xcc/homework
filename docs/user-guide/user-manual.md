# 用户使用手册

法律材料工作台面向内部小组的法律学习、研究和材料处理。它可以帮助提取材料信息、检索法条、发现合同风险和整理分析结果，但 AI 输出不能替代人工判断。

## 登录与工作台

1. 打开系统首页。
2. 注册账号或使用已有账号登录。
3. 登录后进入工作台，查看最近材料、分析、对话和统计。
4. 通过侧边栏进入法条搜索、文档分析、文档对比、聊天、历史和收藏。

普通用户只能看到自己的数据；管理员可以进入管理后台查看系统范围内的基础统计和记录。

## 法条搜索

1. 打开“法条搜索”。
2. 输入法规名称、条款编号或关键词。
3. 使用分类筛选缩小结果范围。
4. 打开结果查看正文、解释和关联信息。
5. 将重要法条加入收藏，或在相关材料中继续追问。

搜索结果来自项目配置的本地法条知识库。没有结果时，可以尝试更短的关键词或去掉具体标点。

## 文档分析

### 推荐流程

1. 打开“文档分析”。
2. 上传脱敏后的合同或法律材料。
3. 等待文件解析和 AI 分析完成。
4. 查看摘要、总体评分和风险列表。
5. 逐条检查风险说明、原文位置、法律依据和修改建议。
6. 对结果进行人工复核后保存或导出报告。

分析结果应重点关注：

- 风险是否对应原文中的真实条款
- 法律依据是否与问题直接相关
- 建议是否符合当前业务背景
- AI 是否明确标出了不确定内容

### 失败处理

- 文件过大或类型不支持：更换格式或压缩文件后重试。
- AI 超时：检查服务状态，稍后重试；不要重复提交大量相同请求。
- 结果为空或明显不准确：保留材料和问题描述，改用更具体的问题重新提问，并人工复核。

## 文档对比

1. 打开“文档对比”。
2. 分别上传旧版本和新版本文件。
3. 等待系统生成变更摘要。
4. 检查新增、删除和修改的条款。
5. 重点确认责任、付款、期限、违约和争议解决等关键变化。

文档对比用于辅助发现差异，不能替代逐条阅读原文。

## 材料上下文问答

1. 从材料详情页进入聊天，或创建一个新会话。
2. 直接说明材料名称和希望解决的问题。
3. 优先提出可验证的问题，例如“这份合同中有哪些付款条件？”
4. 对回答继续追问依据、原文位置和不同解释。
5. 将有价值的回答保存到历史、收藏或笔记。

推荐问题：

- “请用通俗语言解释这一条款。”
- “这项风险对应材料中的哪一段？”
- “请比较这两个版本在违约责任上的差异。”
- “还需要人工确认哪些事实？”

## 历史、收藏和导出

- **历史**：查看以前的分析、对比和对话，并重新打开详情。
- **收藏**：保存常用法条、重要分析或材料。
- **导出**：从分析详情生成 TXT、DOCX 或 PDF 报告。
- **复核**：对 AI 风险标记确认、不准确或待复核状态，并留下人工判断。

导出前应检查材料名称、风险列表、法律依据和结论是否完整。

## 内部使用规范

- 上传前删除姓名、身份证号、联系方式、账号和其他不必要的敏感信息。
- 不把 AI 结果直接作为对外法律意见或最终合同文本。
- 对高风险结论进行人工复核，并记录不同意见。
- 遇到错误结果时保留问题、材料和时间，便于小组统一反馈。
- 不共享账号、Token 或管理员密码。

## 常见问题

### 为什么分析结果需要等待？

文档需要经过读取、文本解析、必要时 OCR，再调用 AI 服务。文件较大或 OCR/AI 服务繁忙时耗时会增加。

### 为什么无法看到别人创建的分析？

普通用户数据按账号隔离。如果确实需要共享，应由管理员或小组约定统一的材料流转方式，不要绕过权限直接访问数据库文件。

### 为什么 AI 回答不一定正确？

AI 可能误读材料、遗漏上下文或错误关联法条。必须回到原文和法条进行核对，无法确认时标记为待复核。
